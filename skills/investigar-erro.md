# Investigar erro

1. **Reproduza** antes de teorizar. Sem reprodução, toda hipótese é igualmente
   plausível e você vai testar a mais confortável.
2. **Leia a mensagem inteira**, inclusive o meio do traceback. A linha que
   estourou raramente é a linha errada.
3. **Confira o que você acha que é verdade.** Imprima o valor em vez de supor.
   A maioria das investigações longas é uma suposição não verificada no começo.
4. Só então proponha a correção — e diga como sabe que ela resolve.

Quando a causa não aparecer, diga o que foi descartado e o que sobrou. Uma lista
honesta do que não é vale mais que um palpite confiante.
